JERI EXPEDITION — landing page
==============================

Estrutura:
  index.html          página completa (o logo está embutido em base64)
  assets/*.webp       fotos otimizadas
  assets/bastidores.mp4 + bastidores-poster.webp

Como publicar (Vercel):
  1. Arraste esta pasta inteira em vercel.com/new  (ou: vercel --prod dentro da pasta)
  2. Nada para instalar: é HTML estático.

Como testar local:
  Abra index.html direto no navegador (mantenha a pasta assets/ ao lado).

Antes de publicar, confirmar com o cliente:
  - CNPJ / razão social, CADASTUR, política de cancelamento (rodapé)
  - E-mail fernandocostajeri@icloud.com (extraído da bandeira na foto da equipe)
  - Preços, caso queira exibir "a partir de R$"
  - Trocar a foto do card Kitetrip por uma foto própria (a atual é de terceiro)
  - Depoimentos reais (a seção de depoimentos escritos foi removida)
